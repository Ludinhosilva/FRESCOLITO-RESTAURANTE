1. INFORMACION INICIAL Y METODOLOGIA
================================================================================

Para complementar la informacion de los audios y realizar un proyecto de
software de alta calidad siguiendo las practicas de Gonzalo (BCP) y Artur
(Globant), se aplico:

ESTRATEGIA DE TESTING Y CALIDAD:
- Piramide de pruebas: Unitarias -> Integracion -> Regresion
- Caja Negra: validar entradas y salidas (formularios)
- Caja Blanca: revisar logica interna, prevenir SQL Injection y XSS
- Cobertura >= 80% (meta profesional)

METODOLOGIA SDD (Spec-Driven Development) CON IA:
- Roles de Agentes: Arquitecto, Disenador de Software, Desarrollador
- Archivos de especificacion .md
- Automatizacion con Hooks (linter, formateador)

PRINCIPIOS SOLID + POO:
- Desacoplar clases para poder aislar en tests
- Abstraccion para que IA y humano puedan testear facilmente

11. MIGRACION A ASTRO
================================================================================

Se migro de React SPA (Vite + React Router) a Astro con React islands.

BENEFICIOS:
- Paginas estaticas (Home, Menu, Nosotros, Galeria): CERO JavaScript
- Solo las paginas interactivas cargan React (Contacto, Reservas, Carrito)
- Bundle JS reducido de ~250KB a ~50KB
- 100/100 Lighthouse potencial
- File-based routing (mas simple que React Router)
- Imagenes optimizadas nativamente

CAMBIOS REALIZADOS:
- astro.config.mjs creado con integracion React
- package.json scripts cambiados de vite a astro
- src/pages/ convertidas a .astro (index, menu, nosotros, galeria, contacto, reservas)
- Componentes React movidos a src/components/react/ como islas
- src/layouts/BaseLayout.astro con layout global
- Componentes Astro creados: Navbar, Footer, Hero, MenuSection, BusinessHours, CartWidget
- Antiguas paginas React renombradas a _*.jsx (backup)

12. CARRITO DE COMPRAS + WHATSAPP
================================================================================

FLUJO DEL CARRITO:
1. Usuario hace clic en "+ Agregar" en cualquier plato del menu
2. El item se guarda en localStorage (persiste al recargar)
3. CartWidget muestra badge con el contador de items
4. Al hacer clic en el badge, se abre CartDrawer (drawer lateral)
5. En el drawer se puede:
   - Ver lista de items con precios
   - Aumentar/disminuir cantidad (+/-)
   - Activar "Para llevar" (agrega S/2 por plato)
   - Agregar notas
   - Ver subtotal, comision y total
6. Al enviar, se abre WhatsApp con el mensaje generado

MENSAJE DE WHATSAPP GENERADO:
  "Hola FRESCOLITO, quiero hacer un pedido:
   1. 2x Ceviche Simple - S/ 20.00
   2. 1x Arroz con Mariscos - S/ 20.00

14. COMISION PARA LLEVAR
================================================================================

Cuando el usuario activa "Para llevar" en el carrito:
- Se agrega S/ 2.00 por cada plato
- Se muestra desglose: Subtotal -> Comision -> Total
- Cada item muestra "+ S/ 2.00 envio"
- El mensaje de WhatsApp incluye la comision

Configurable en src/utils/whatsapp.js:
  COMMISSION_PER_ITEM = 2.00
